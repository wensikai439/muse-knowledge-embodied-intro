# 课堂理论知识

课堂上讲的理论知识。

这个夹放的是上课、看课、读书时学的理论：模型是怎么搭的、算法是怎么推的、训练是怎么做的。先把理论弄懂，再去动手。

## 不放什么

纯感知模型、不写代码的空谈；强化学习的实战内容放 06-强化学习。
