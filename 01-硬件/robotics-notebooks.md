## sikai 为什么收它

这是社区做的中文机器人知识库：**不是资源收集箱，是把技术栈拆成互相链接的知识页，每个概念讲清是什么、为什么重要、和哪些概念相关**。它有一条从运动控制一路走到 Physical AI（具身智能）的全栈路线，Sim2Real 那一节直接给了部署检查清单——现象、原因、排查方向一张表，正好补 01-硬件里“真机部署”的中文资料。

## 它到底是什么

一个机器人工程知识库（wiki），带知识图谱和在线站。首页按目标给入口，主路线是“运动控制 → 物理智能全栈成长路线”：控制 → 学习 → Sim2Real → Transformer / VLA（Vision-Language-Action，视觉-语言-动作模型）/ 世界模型 → 部署。下面还有 30 多条纵深路线，每条按起点里程碑的历史顺序排：PCB 设计、遥操作、火箭回收控制、力矩电机设计、传统控制、整机硬件、安全控制、接触操作、导航、模型架构、模仿学习、强化学习、移动操作、人形足球、动作重定向、跨本体迁移、仿真到真机、人形拳击、具身上下文学习、人形行为基础模型、具身测评、感知越障、动作生成、扩散与流匹配策略、VLA、真实到仿真、具身数据、世界-动作模型。

### 和真机部署直接相关的三页

- **Sim2Real（仿真到真机迁移）**：wiki/concepts/sim2real.md，讲策略成立的条件——动作、观测、时序、身体、地面这几类条件要同时对齐；
- **Sim2Real 工程清单**：wiki/queries/sim2real-checklist.md，从仿真训练到真机部署的逐项核查：模型文件版本与训练代码一致、观测空间维度与顺序和真机接口逐字段核对、动作空间映射（仿真关节顺序 ↔ 真机 CAN ID 顺序）、推理延迟 < 5ms、初始姿态与仿真一致（误差 < 5°）。调试端按现象给排查方向：上机立刻摔倒→观测顺序错；原地抖动→控制频率不匹配；向一侧漂移→IMU 安装偏差；步伐极小→命令归一化错；关节力矩饱和→力矩映射错；
- **Sim2Real 差距缩小**：wiki/queries/sim2real-gap-reduction.md，五阶段工程清单（建模 → 域随机化 → 仿真验证 → 系统辨识 → 上机 → 差距闭环），上机前 3 分钟快速检查版也在同一页。

## 从哪开始

1. 先打开在线站，点“主路线：运动控制 → 物理智能全栈成长路线”，确认整条路长什么样；
2. 直接去 Sim2Real 那一页，再读工程清单那一页，照着清单逐项核对；
3. 有明确方向时再按目标选一条纵深路线（比如强化学习运动控制、模仿学习、VLA），不要从头通读。

## 对具身有什么用

sikai 的主线以后要上真机，这个库就是中文的“上真机之前先查一遍”的地方：Sim2Real 清单能当部署前的检查表，纵深路线能当学某个方向的地图。它和 01-硬件里的 SO-101 HIL-SERL 实战博客是互补的：那篇讲一个人具体踩了什么坑，这篇讲部署前要系统地查什么。
