## 放什么

机器人本体、关节、夹爪、传感器、执行器、运动学 / 动力学入门。FK（Forward Kinematics，正运动学）、IK（Inverse Kinematics，逆运动学）这些身体怎么动的理论也放这里。

真机部署：仿真到真机的迁移、真机调试、部署踩坑与实战经验——仿真里跑通的东西怎么搬到真机上、搬过去会出什么问题、别人是怎么调通的，都放这里。

## 不放什么

仿真器、评测方法、软件算法。
