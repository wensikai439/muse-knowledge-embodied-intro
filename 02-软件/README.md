# 软件

让机器人动起来的软件：看见、学会、仿真里练、拿来就用的工具。

## 里面有什么

| 文件 | 一句话 |
|---|---|
| `rl-notes-cs285.md` | Berkeley CS285 深度强化学习笔记，中文，跟着一门好课从头讲到尾 |
| `agentic-rl-lab.md` | Datawhale 的 Agentic RL 复现项目，GRPO / GSPO / DAPO，能跑起来 |
| `agent-learning-ch10-agentic-rl.md` | 《从零开始学 Agent》第 10 章，重点是 10.2 节 SFT + LoRA |

## 放什么

- 感知：视觉、语言、触觉、状态估计、世界模型、图像差异、VLM 感知；
- 强化学习：好教程、综述、经典算法、代码实现、奖励设计、探索。现阶段里面是 RL-notes（CS285）、Agentic RL Lab、从零开始学 Agent 第 10 章；
- 仿真与评测：仿真器、基准、任务清单、评分器、harness、评测方法、多种子统计；
- 工具与开源仓库：开源项目、科研仓库、科研画图工具、实验工具、sikai 自己常用的工具。

真机部署的实战经验不放这里，放 01-硬件。

## 不放什么

纯硬件资料；只抄关键词的摘要、未读原文就写的精读。
