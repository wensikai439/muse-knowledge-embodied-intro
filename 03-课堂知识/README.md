# 课堂知识

课堂上讲的理论知识，加上入门的地图和术语。

## 里面有什么

| 文件 | 一句话 |
|---|---|
| `diy-llm-cs336.md` | Stanford CS336 中文版，从零手搓大模型，16 章 + 6 个作业 |
| `manipulation-mit.md` | MIT 机器人操作课程讲义，12 章 + 附录，基于 Drake 动手 |

## 放什么

- 入门地图：具身智能是什么、由哪几块组成、学什么、按什么顺序学；
- 术语表：每个术语从零定义，配一个最简单的例子；
- 课堂理论：上课、看课、读书时学的理论，模型是怎么搭的、算法是怎么推的、训练是怎么做的。现阶段里面是 Diy-LLM（Stanford CS336 中文版）。

## 不放什么

纯感知模型、不写代码的空谈；强化学习的实战内容放 02-软件。
