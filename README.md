# 小墨奇的知识库积累（具身入门）

> 面向刚进入具身领域的小白 sikai，帮助他快速建立对具身智能的基本认识，了解如何找高质量资料、如何读、如何把一个东西学透，再落到自己的论文和实验上。

这是一个公开仓库（Public）。不要放密码、密钥、验证码、私人账号信息、个人隐私。

目前没有加任何许可证（LICENSE）。公开不等于别人可以随便用，没有许可证默认是 sikai 保留全部权利。许可证等 sikai 定，见下面“许可证”一节，先别急着加 MIT。

## 为什么做这个项目

sikai 是刚进入具身领域的大学生，主线是 code-as-policy 的论文和 harness：要做出能泛化的机器人策略代码，还要在 benchmark 上打赢裸 Codex。

但刚入门时，最难的不是某一个算法，而是没有地图：具身智能由哪几块组成、要按什么顺序学、哪些资料是真的好、哪些只是标题好听。网上资料很多，质量参差不齐，搜到的第一个结果往往不是最好的那个。

所以这个库只做一件事：**只收高质量的、sikai 亲自点头的资料，每样东西都写清它好在哪、对应哪个环节、能不能直接用、核实过没有。** 不做随手收藏，不做链接堆砌。

这个项目仍处在早期阶段，后面会随着 sikai 的学习不断更新。如果你觉得这个项目对你有帮助，请点亮右上角的 ⭐️ Star ⭐️！

## 适合谁阅读

- 刚进入具身领域、想从零开始的本科生、硕士生；
- 想系统了解机器人策略、强化学习、仿真评测的同学；

如果你已经是具身领域的专家，这个库可能太浅了，它是给入门者搭的地图，不是给专家看的综述。

## 快速开始

如果你是第一次打开这个库，按这个顺序读：

1. 先读这篇 README，确认你是它的读者，确认品味线；
2. 再读 `01-入门地图`，建立全景；
3. 遇到不懂的词，去 `02-术语表` 查从零定义；
4. 想学强化学习，直接去 `06-强化学习`，先读 RL-notes 的 Preliminaries，再读从零开始学 Agent 的 10.2；

## 许可证：先别加 MIT

- **公开 ≠ 别人可以随便用。** 没有许可证，你默认保留全部权利，别人只能看、不能合法地复制、分发、改编或商用（GitHub 条款只允许浏览和 fork）。
- **MIT 是最放的那个。** 加了 MIT，任何人都可以拿去用、改、卖、闭源商用，不用给你钱，只要留你的署名。它适合想让人随便用的开源代码，不适合想保知识产权、想收钱的内容库。
- **这个库是笔记和资料整理，不是代码。** 更合适的是内容许可证，例如 `CC BY-NC-SA 4.0`（署名-非商业性-相同方式共享）：别人可以非商业使用、要署名、改完也要用同样条件分享；商业使用要先找你谈。想更严就先不加许可证，保持全部权利保留，商业使用一律找你谈。
- 所以现在**先不加任何 LICENSE**，等你定：是要 `CC BY-NC-SA 4.0`，还是保持不加（全部权利保留），还是另有打算。你定一句，我再加。
