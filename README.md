## 这个库是给谁的、用来干什么的

给刚进入具身领域的小白 Mark 用的，收的是**高质量资料**，不是随手收藏：

- 强化学习里非常好的资料
- 科研里好用的仓库，例如南大、港大的科研仓库
- 科研画图工具、实验工具、好用的开源项目

每样东西进来时都要写清：它好在哪、对应哪个环节、能不能直接用、核实过没有。

## 分类逻辑：怎么分的，为什么这样分

按**学习路径 + 机器人干活的闭环**分，不按来源分：

1. **先有地图（01）**：具身智能是什么、由哪几块组成、要学什么。
2. **再有词（02）**：每个词第一次出现就从零定义，这是全库的字典。
3. **再走一遍闭环（03–06）**：机器人干活就是一个循环——
   `感知（03，看见与理解世界）→ 策略与代码（05，决定怎么做、写出 solve()）→ 本体与硬件（04，身体怎么执行）→ 强化学习（06，靠试错和奖励学会做事）`
   强化学习单列一夹，是因为你要重点收这方面的好资料，不适合把它藏在“学习与泛化”这种大而空的夹子里。
4. **再学怎么量（07）**：仿真与评测，怎么知道做得好不好。
5. **最后是来源与能用的东西（08–09）**：`论文精读（08，每篇只讲思想）→ 工具与开源仓库（09，科研仓库、画图工具、开源项目、你自己常用的工具，全放这一个夹）`

工具不再分两夹：开源项目、科研仓库、画图工具、自用工具，本质上都是“拿来就能用的东西”，分开只会重复。

一句话记：**地图 → 词 → 感知 → 决策/执行 → 强化学习 → 评测 → 论文 → 工具与仓库。**

## 许可证：先别加 MIT

- **公开 ≠ 别人可以随便用。** 没有许可证，你默认保留全部权利，别人只能看、不能合法地复制、分发、改编或商用（GitHub 条款只允许浏览和 fork）。
- **MIT 是最放的那个。** 加了 MIT，任何人都可以拿去用、改、卖、闭源商用，不用给你钱，只要留你的署名。它适合想让人随便用的开源代码，不适合想保知识产权、想收钱的内容库。
- **这个库是笔记和资料整理，不是代码。** 更合适的是内容许可证，例如 `CC BY-NC-SA 4.0`（署名-非商业性-相同方式共享）：别人可以非商业使用、要署名、改完也要用同样条件分享；商业使用要先找你谈。想更严就先不加许可证，保持全部权利保留，商业使用一律找你谈。
- 所以现在**先不加任何 LICENSE**，等你定：是要 `CC BY-NC-SA 4.0`，还是保持不加（全部权利保留），还是另有打算。你定一句，我再加。
