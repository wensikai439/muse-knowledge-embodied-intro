## 为什么做这个项目

sikai 是刚进入具身领域的大学生，主线是 code-as-policy 的论文和 harness：要做出能泛化的机器人策略代码，还要在 benchmark 上打赢裸 Codex。

但刚入门时，最难的不是某一个算法，而是没有地图：具身智能由哪几块组成、要按什么顺序学、哪些资料是真的好、哪些只是标题好听。网上资料很多，质量参差不齐，搜到的第一个结果往往不是最好的那个。

所以这个库只做一件事：**只收高质量的、sikai 亲自点头的资料，每样东西都写清它好在哪、对应哪个环节、能不能直接用、核实过没有。** 不做随手收藏，不做链接堆砌。

这个项目仍处在早期阶段，后面会随着 sikai 的学习不断更新。如果你觉得这个项目对你有帮助，请点亮右上角的 ⭐️ Star ⭐️！

如果你已经是具身领域的专家，这个库可能太浅了，它是给入门者搭的地图，不是给专家看的综述。

## 快速开始

如果你是第一次打开这个库，按这个顺序读：

1. 先读这篇 README，确认你是它的读者，确认品味线；
2. 再读 `03-课堂知识`，建立全景，遇到不懂的词查里面的术语表；
3. 想学强化学习，直接去 `02-软件`，先读 RL-notes 的 Preliminaries，再读从零开始学 Agent 的 10.2；
4. 想学怎么做科研、怎么写论文，去 `04-科研论文`，先读南大 Research-Starter-Kit，再读港科大 Supervisor-Skills。
