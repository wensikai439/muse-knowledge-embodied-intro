# 科研方法与论文写作

怎么做科研、怎么写论文、怎么找问题。

以前这个夹叫“论文精读”，名字和内容对不上：精读是读某一篇论文，但这个夹里放的是科研入门、找问题的方法、写论文的方法、AI 科研技能，是“怎么做科研”这一整套东西，不是单篇论文的精读。改成现在这个名字，看到名字就知道里面是什么。

## 放什么

科研入门指南、找问题的方法、读论文的方法、想 Idea 的方法、写论文各部分（摘要、引言、方法、实验、参考文献）、科研画图、Rebuttal、AI 科研技能。每篇按 sikai 的规矩写：发现了什么问题、关键办法是什么、对哪个环节有用、开源吗，术语第一次出现就解释。

## 不放什么

只抄关键词的摘要、未读原文就写的精读；单个机器人任务的规范，那些不在这里。

## 入库规矩

没有 sikai 亲自批准，不往这里放东西。sikai 指名后，文件名用英文小写加 `-`，标题第一行写中文名，开头写来源、日期、为什么收它，不确定的写“未核实”。
