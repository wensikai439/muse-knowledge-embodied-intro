# 决策、规划与控制

机器人想清楚做什么、怎么做、再把动作发给身体。

以前这个夹叫“策略与代码”，太笼统了：策略可以指很多东西，代码又太泛，看不出这个夹到底管哪一步。改成现在这个名字，是因为机器人干活分三步，一步都不能少：

1. **决策**：现在该做什么？先抓还是先开门？
2. **规划**：具体怎么做？走哪条路、手走哪条轨迹？
3. **控制**：把动作发给身体，让关节、夹爪真的动起来。

sikai 主线里的 code-as-policy，就是把这三步写成一份能跑的 `solve()` 代码：代码就是策略，策略就是代码。

## 放什么

规划、决策、VLA、code-as-policy、控制、调试循环、验证器。强化学习单列在 06-强化学习，不放这里。

## 不放什么

纯感知模型、不写代码的空谈。
