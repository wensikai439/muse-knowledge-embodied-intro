## sikai 为什么收它

这是 sikai 定的品味线之一：**不是星数高就好，是讲得清楚、按一门好课从头讲到尾才好**。这份笔记跟的是 Berkeley CS285（Deep RL，Sergey Levine 的课），从“强化学习是什么”开始，一讲一个笔记，一直讲到离线强化学习、逆强化学习、强化学习与语言模型、迁移学习。

## 它到底是什么

作者自学 CS285 时记的笔记，有两套平行的体系：

- **笔记**：紧贴 CS285 一讲一个单位，含 PPT 和课堂上讲的、PPT 上没有的内容，每讲末尾可能有 Reference Papers；
- **Tutorial**：作者后来重排的、更适合初学者的体系，逻辑顺序重新整理过，含大量代码实现，还在开发中。

目录（按笔记体系，0–23 讲）：预备知识、什么是强化学习、模仿学习、PyTorch 基础、强化学习入门、策略梯度、Actor-Critic、价值函数方法、Q 学习、进阶策略梯度、最优控制与规划、基于模型的强化学习（两讲）、探索（两讲）、离线强化学习（两讲）、强化学习理论、变分自编码器、软最优性、逆强化学习、强化学习与语言模型、迁移与元学习、挑战与开放问题。另有一个 Takeaway / Cheatsheet，汇总了各讲要点。

## 从哪开始

1. 先读 README 开头的 Preliminaries：它先提醒你记号会混乱，符号一会儿一个意思，这是强化学习里真实的坑；
2. 再读“What is RL”和“为什么已经有物理了还要强化学习”这两节：它用小狗、开车、发射火箭讲清强化学习相对纯物理控制的优势——环境是黑盒，出了意外能感知、能恢复；
3. 需要查某算法时再按目录跳讲，配合 Takeaway 当速查表。

## 对具身有什么用

具身的决策和学习，最后都要落到“状态 → 动作 → 奖励 → 下一状态”这个循环上。这份笔记把这个循环的算法族（策略梯度、Actor-Critic、Q 学习、基于模型、离线强化学习）按课的顺序讲全了，是 06-强化学习夹里的地基。机器人那边的奖励、探索、样本效率问题，在这里都能找到对应的概念。
